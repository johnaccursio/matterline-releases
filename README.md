# BenchRead Practice releases

Installers for BenchRead Practice (formerly Matterline), a practice management app for law firms.  This repository holds release files only; there is no source code here.  It keeps the name matterline-releases because installed copies check it for updates.

BenchRead Practice checks this page for new versions and updates itself:

- Windows: new versions download in the background and install when you restart BenchRead Practice.
- Mac: BenchRead Practice tells you when a new version is out and opens the download.  It will update itself once the app is signed by Apple.

Your data stays on your computer.  BenchRead Practice copies it to its backups folder before every update.

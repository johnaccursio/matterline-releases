# Matterline releases

Installers for Matterline, a practice management app for law firms.  This repository holds release files only; there is no source code here.

Matterline checks this page for new versions and updates itself:

- Windows: new versions download in the background and install when you restart Matterline.
- Mac: Matterline tells you when a new version is out and opens the download.  It will update itself once the app is signed by Apple.

Your data stays on your computer.  Matterline copies it to its backups folder before every update.
